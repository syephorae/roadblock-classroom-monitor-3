# **App Name**: Roblox Classroom Monitor

## Core Features:

- Teacher Authentication: Secure authentication system for teachers to log in and access student data.
- Student Progress Tracking: Monitor individual student's progress within the Roblox experience.
- Time Played Monitoring: Track the amount of time each student spends in the Roblox experience.
- Automated Recommendations: Generative AI tool to provide teachers with personalized insights and recommendations based on student performance data.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) to create a calm and trustworthy environment.
- Background color: Light gray (#F5F5F5) for a clean and professional look.
- Accent color: Subtle green (#81C784) for highlighting key data points and positive progress indicators.
- Body and headline font: 'Inter', a sans-serif for clear and accessible readability.
- Use clear, consistent icons to represent different metrics and actions. Favor filled icons for emphasis.
- Use a clean and organized layout, focusing on data visualization with charts and graphs. Prioritize clarity and ease of navigation.
- Subtle transitions for loading data and updating charts.
